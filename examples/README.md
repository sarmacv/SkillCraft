# Examples

- `empty/` — an empty folder. Launch "Run SkillCraft (empty folder)" to try the greenfield flow.
- `brownfield/` — a deliberately messy existing skill (bad name, vague description, a fake hardcoded key, a misplaced script, a broken link, an orphan file, human docs in the skill folder). Launch "Run SkillCraft (existing skill)" to watch SkillCraft find and fix the gaps.

The key in `brownfield/` is fake.
