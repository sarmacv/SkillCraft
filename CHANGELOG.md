# Changelog

## 0.1.0

First release.

- Orchestrator canvas: drag-and-drop entry points, sources (REST, GraphQL, MCP, references, knowledge bases, databases, files, web, CLI), modules and outputs, with placeholders you can type later.
- `@skillcraft` chat participant: create a skill through conversation, review, add components, explain.
- AI coach that asks focused questions and turns answers into proposals.
- Proposal system: every change is previewed as a diff (or a dashed node on the canvas) and needs your approval; rejections are remembered; undo.
- Health checks: structure, integrity, efficiency (context budget), portability, workflow.
- Brownfield import: detects existing skills, reverse-engineers the workflow, proposes fixes.
- Code generation in Python, Node.js or Bash.
- Tailored or universal builds for Claude Code, OpenAI Codex and GitHub Copilot, with README.md, SETUP.md and install scripts.
- Quick tests with your VS Code model and real agent tests with each tool's CLI.
